# TADSS-Runtime — Decision Runtime Platform

Nền tảng thực thi quyết định đặt chỗ chịu lỗi (Đồ án 2 → khoá luận). SmashCourt-BE gửi `POST /api/v2/decisions`;
runtime chọn strategy qua `IStrategyRegistry`, bọc trong Polly v8 pipeline (budget 500ms → fallback `APPROVED` cọc 100%, D-13),
cache `StrategyDecision` (Redis L2 / IMemoryCache L1), ghi audit bất biến vào PostgreSQL schema `tadss`; có `GET /api/v2/decisions/{id}`,
`GET /api/v2/decisions/pending-approvals`, `POST .../override`, `POST .../outcome`. Mọi `/api/*` cần `X-Api-Key` (gói 5.3). Thuộc workspace 4 repo — xem `../CLAUDE.md`.

## Lệnh
```bash
dotnet restore TADSS.slnx
dotnet build TADSS.slnx -c Release -nologo -v q --warnaserror          # PHẢI 0 warning
dotnet test  TADSS.slnx -c Release --no-build --filter "FullyQualifiedName~TADSS.UnitTests"
dotnet test  TADSS.slnx -c Release --no-build --filter "FullyQualifiedName~TADSS.IntegrationTests"   # cần Docker (Testcontainers)
docker compose up -d --build                                            # MỘT lệnh chạy cả tadss-runtime (localhost:8081; Development; Neon + Redis Cloud + API key từ appsettings.Development.json được copy vào image như SmashCourt-BE, image chỉ dùng local) + ngrok (URL công khai ở http://localhost:4040, đổi mỗi lần khởi động lại; cần NGROK_AUTHTOKEN trong .env) + Grafana (http://localhost:3001; dashboard "TADSS Runtime" nạp sẵn, TADSS gửi trace/metric/log qua OTLP); cần mạng external: docker network create smashcourt-network; dừng: docker compose down (dev hằng ngày dùng dotnet run)
dotnet run --project src/TADSS.Runtime.Api                              # http://localhost:5296/swagger; mọi /api/* cần X-Api-Key (thiếu key trong appsettings.Development.json thì 401)
bash tools/expose/verify-expose.sh                                      # NG-1/2/3/5 + SEC-6 bằng Docker thật (project compose riêng, không cần ngrok)
bash tools/evaluation/run.sh [quick|full] [--clean]                     # chế độ đánh giá một lệnh (tự build image; --clean dọn sạch ~6 GB sau khi chạy)
bash tools/observability/verify-observability.sh                        # OB-2/OB-4: dashboard nạp + metric TADSS tới Prometheus (Docker thật, mạng riêng, không ngrok/Neon)
ASPNETCORE_ENVIRONMENT=Testing ConnectionStrings__DefaultConnection="Host=localhost;Database=x" dotnet ef migrations list --no-connect --project src/TADSS.Infrastructure --startup-project src/TADSS.Runtime.Api   # EF chỉ đọc; migration nằm ở Infrastructure; chuỗi kết nối giả vì design-time khởi động host mà validator từ chối ô giữ chỗ trong appsettings.json (không phải secret, không mở kết nối)
```
CI: restore `--locked-mode` → quét lỗ hổng (`tools/ci/check-vulnerable-packages.sh`) → build Release → unit test → integration test (Testcontainers) → Docker build + kiểm user non-root; job `expose-check` chạy `verify-expose.sh`; job `observability-check` chạy `verify-observability.sh`; job `evaluation-tools` chạy pytest của evaluator/evidence và build image evaluator (không chạy). Nhánh làm việc chính: `develop`.
Expose qua ngrok: `docker compose up -d --build` (một file `docker-compose.yml`, không profile; biến `NGROK_AUTHTOKEN` trong `.env`, mẫu `.env.example`; chi tiết README mục "Chạy bằng Docker và expose qua ngrok"). `packages.lock.json` lệch sau khi nâng package: `dotnet restore --force-evaluate` rồi commit lock file.

Chuỗi kết nối PostgreSQL thiếu/giữ chỗ → không khởi động ở mọi môi trường (`DatabaseOptionsValidator`). Health: chỉ `/health/live`, `/health/ready` (không còn `/health`). - Lỗi → `ExceptionClassifier` (hàm thuần) + `GlobalExceptionHandler`: mất kết nối PostgreSQL (lỗi tạm thời) → 503 `PERSISTENCE_UNAVAILABLE`; mã lỗi ở `ErrorCodes` của SDK. Audit ghi đồng bộ (fail-closed), `created_at` do `DecisionService` gán (µs, UTC) — không còn interceptor.
- `TreatWarningsAsErrors` + XML doc bắt buộc ở SDK/Strategies; version package chỉ khai báo trong `Directory.Packages.props`.
- Options: `{X}Options` với `SectionName = "Tadss:{X}"` + `{X}OptionsValidator` + `ValidateOnStart()`, đặt trong thư mục `Options/` của project sở hữu; strategy chọn theo từng request qua `Tadss:Routing` (`DefaultStrategy` + `Rules`, nạp lại nóng; Application nhận cấu hình qua port `IRoutingRulesSource`, adapter ở `Infrastructure/Configuration`). Khóa cũ `Tadss:Strategy:ActiveStrategyName` đã gỡ (chỉ còn sinh Warning).
- Lỗi API trả RFC 7807 `ProblemDetails`; header idempotency xem `TADSS.Runtime.Api/Common/HttpHeaderNames`; giới hạn 128 ký tự của contract ở `Application/Common/ContractLimits`.
- Migration EF (schema `tadss`) chỉ tạo/áp dụng khi người dùng yêu cầu; `20261002101457_DecisionPersistenceV2` **xóa** bảng v1 và chưa được áp lên Neon. Không đọc/sửa `appsettings.Development.json`, `.env`.

## Quy tắc làm việc
- **Không tự ý `git commit` / `push` / `merge` / `rebase` / `reset`** — chỉ khi người dùng yêu cầu rõ ràng (xem `../.claude/rules/git-safety.md`).
